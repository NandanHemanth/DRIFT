Concepts in 60 seconds

Bitemporal fact

Every fact stores valid time (when true in the world) and ingestion time (when the agent learned it). A contradiction on a functional predicate (lives_in, works_at…) closes the old fact's valid window instead of deleting it — that's what P2 exploits.

Staleness

An answer is stale when it contains the superseded fact ("Boston" after the move to Seattle). Accuracy alone hides this failure mode; DRIFT measures it separately.

Swarm topologies

shared: N writers, one memory — tests contention. independent: N private memories with 80% observation — tests variance. orchestrator: router LLM assigns questions to specialist workers over shared memory — tests the production read pattern.
